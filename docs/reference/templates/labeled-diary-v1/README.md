# Labeled Diary Template v1

Place the current canonical labeled diary reference assets in this folder.

Suggested contents:
- one or more screenshots of the intended student-facing layout
- any annotated image showing which labels map to which parsed fields
- a short note if the template changes in a way that affects deterministic parsing

Recommended filenames:
- `labeled-diary-v1-overview.png`
- `labeled-diary-v1-annotated.png`
- `labeled-diary-v1-notes.md`

Why this folder exists:
- to keep parsing assumptions visible and versioned
- to give agents and humans one stable place to check when parser work is under discussion
- to avoid scattering screenshots across desktop folders or chat history
